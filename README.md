# Repositorio Académico de Tesis (RAT)

Sistema web desarrollado con Laravel para la gestión y consulta de tesis académicas.

## Tecnologías utilizadas
- Laravel
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Funcionalidades
- Registro de tesis
- Gestión de usuarios
- Consulta de trabajos académicos

## Instalación
1. Clonar repositorio
2. Ejecutar `composer install`
3. Configurar `.env`
4. Ejecutar migraciones
